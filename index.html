        Take Something Apart

        Name an object, drop in a photo of one, or both. Claude designs every part and how it comes apart; this takes a minute or two.

        Add your Anthropic API key in to generate new objects.

        Settings

        Only used to ask Claude to design new objects. It's saved in this browser only and sent straight to Anthropic, nowhere else. The built-in rocket works without it. Get a key at console.anthropic.com.

        Feedback

        What's working, what isn't, what you'd like to take apart next. Send opens a pre-filled GitHub issue; nothing is sent until you submit it there.
